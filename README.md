# Техномир

Учебный проект, дни 10–11.

Сделана статическая копия сайта «Техномир»: HTML и CSS повторяют готовый дизайн 1:1. Готовы шапка-островок, категории, карточки товаров, отзывы, все страницы и футер. Адаптив и `clamp` не используются.

JavaScript пока пустой. Корзина, покупки, фильтры, вход и отправка форм не работают. Товары, категории, отзывы и заказы записаны в HTML как заглушки.

## Структура

- public — страницы, стили, пустой JavaScript, иконки и картинки
- src — пока пустые файлы сервера, API и базы данных
- database.db — пока пустой файл под будущую базу
- .env — настройки окружения

## Как открыть

Запустите статический сервер из папки `public` и откройте `http://localhost:3300/index.html`.
