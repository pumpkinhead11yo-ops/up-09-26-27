# Техномир

Учебный проект, день 13.

Полностью рабочая версия сайта «Техномир» – интернет-магазина электроники в Оренбурге. Сделана адаптивная вёрстка с `clamp()`: сайт удобен на экранах от 425 px до больших мониторов. Данные хранятся в SQLite, сервер написан на Node.js и Express, интерфейс – обычные HTML, CSS и JavaScript без фреймворков.

## День 13: адаптивная верстка с clamp()

Что делалось:

- проверил сайт на разрешениях 425 px (мобильный), 768 px (планшет), 1024 px и 1440 px (десктоп);
- добавил media queries для основных breakpoints;
- заменил фиксированные размеры шрифтов и отступов на `clamp()`, чтобы они плавно менялись с шириной экрана;
- сделал бургер-меню на мобильных;
- проверил, что картинки не выходят за границы контейнеров;
- убрал горизонтальную прокрутку на всех проверенных разрешениях.

Результат: сайт корректно отображается на 425, 768, 1024 и 1440 px, шрифты и отступы масштабируются плавно, меню на телефоне превращается в бургер, изображения не вылезают за контейнеры, горизонтальной прокрутки нет.

## Что умеет сайт

- поиск, фильтры и сортировка в каталоге;
- карточка товара с характеристиками и отзывами;
- сравнение товаров, корзина с сохранением в `localStorage`;
- оформление заказа и отслеживание по номеру заказа или телефону;
- регистрация, вход, личный кабинет с историей заказов;
- отправка сообщений через форму обратной связи;
- светлая и тёмная темы;
- мобильная версия с бургер-меню;
- админ-панель: статистика, товары, категории, заказы, отзывы, сообщения и пользователи.

Все кнопки, авторизация, фильтрация и поиск работают через API сервера.

## Запуск

Нужен Node.js версии 22.5 или новее – используется встроенный модуль `node:sqlite`.

```
npm install
npm start
```

Сайт открывается по адресу http://localhost:3000. Для автоматической перезагрузки сервера при изменении файлов:

```
npm run dev
```

Настройки лежат в `.env`:

- `PORT` – порт сервера, по умолчанию 3000;
- `DB_FILE` – путь к файлу базы данных, по умолчанию `database.db`.

## База данных

На сайте написана база данных на SQLite. Файл `database.db` лежит в корне проекта. При первом запуске он создаётся и заполняется тестовыми данными: категории, товары, отзывы, заказы, пользователи и сообщения. При повторном запуске данные не дублируются. Пароли хранятся в хешированном виде.

## Структура

- `public` – страницы, стили, скрипты, иконки и изображения;
- `public/css` – `reset.css`, `style.css`, `pages.css`, `admin.css`;
- `public/js` – `script.js` и `admin.js`;
- `src/server.js` – запуск сервера;
- `src/routes/api.js` – API;
- `src/models/database.js` – подключение к SQLite;
- `src/models/initDatabase.js` – создание и заполнение базы;
- `src/models/catalog.json` – данные каталога;
- `database.db` – файл базы данных SQLite.

Шрифт Inter подключается с Google Fonts, иконки – Lucide.

## API

Все запросы идут с префиксом `/api`. Основные маршруты:

- `GET /categories`, `GET /products`, `GET /products/:id`, `GET /products/:id/reviews`;
- `POST /products/:id/reviews`, `GET /reviews/latest`, `GET /stats`;
- `POST /auth/register`, `POST /auth/login`, `POST /auth/logout`, `GET /auth/me`;
- `POST /orders`, `GET /orders/track`, `GET /orders/my`;
- `POST /messages`;
- `/admin` – статистика и управление товарами, категориями, заказами, отзывами, сообщениями и пользователями.
