# Техномир

Учебный проект, день 8-9. На этом этапе сделана структура папок и HTML-разметка четырёх страниц: главной, каталога, страницы «О нас» и «Контакты».

В разметке использованы семантические теги: header, nav, main, section, article, footer. Стили и JavaScript пока пустые, сервер и база данных не написаны. Товары, категории и отзывы добавлены вручную как заглушки, вместо карты текст-заглушка.

## Структура

- public – страницы, пустые CSS и JS, изображения
- src – пока пустые файлы сервера, API и работы с базой данных
- database.db – пока пустой файл под будущую базу
- .env – настройки окружения

## Как открыть

Откройте `public/index.html` в браузере. Страницы связаны ссылками друг с другом.
