# Техномир

Учебный проект, день 12.

Сделана статическая копия сайта «Техномир»: HTML и CSS повторяют готовый дизайн 1:1. Готовы шапка-островок, категории, карточки товаров, отзывы, все страницы и футер. Адаптив и `clamp` пока не используются.

Подключён `public/js/script.js`: элементы находятся через `querySelector`, работают обработчики `click`, `submit` и `input`, бургер-меню, валидация формы обратной связи с ошибками под полями и модальное окно успеха.

Корзина, покупки, фильтры, вход и отправка данных на сервер не работают — форма проверяется только в браузере. Товары, категории, отзывы и заказы записаны в HTML как заглушки.

## Структура

- public — страницы, стили, JavaScript, иконки и картинки
- src — пока пустые файлы сервера, API и базы данных
- database.db — пока пустой файл под будущую базу
- .env — настройки окружения

## Как открыть

Запустите статический сервер из папки `public` и откройте `http://localhost:3300/index.html`.
